# Cala Renee Salon

Mobile-first static site for **calareneesalon.com**. Services, prices, and stylist copy come from a local seed and, when live, [cmspeak](https://cmspeak-production.up.railway.app).

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Content

Edit `public/content/cala-renee.json`, or sign in at cmspeak `/admin` and launch this site. The overlay script is `cmspeak.js` with site slug `cala-renee`.

## Railway

Serve with `npm start`. Custom domain: `calareneesalon.com`.
